# Simple USAGE
### FIRTS STEP
```
curl -fsSL -o /tmp/nvidia-install.sh https://raw.githubusercontent.com/Neko-Void-Linux/nvidia-support/refs/heads/main/install.sh 
```
### SECOND STEP RUN WITH SUPERUSER PERMISSIONS
```
sudo bash /tmp/nvidia-install.sh latest
```
or  
```
doas bash /tmp/nvidia-install.sh latest
```
Note: You can replace "latest" to other version of nvidia driver : 390 . 470 , 580
